# 🗞️ TechCrunch Digest — Локальный парсер и дайджест новостей

Простой, автономный скрипт на Python, который:

- Парсит свежие статьи с [TechCrunch](https://techcrunch.com/)
- Формирует краткий дайджест в виде списка ссылок
- Сохраняет результат в локальную SQLite-базу
